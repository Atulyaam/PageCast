## 3. Architecture & Domain Model Verification

### 3.1 Pure Domain Isolation
As mandated by the PageCast Architecture Specification (`docs/ARCHITECTURE.md`), the entire `src/domain/` directory is strictly decoupled from framework code:
- **0 dependencies on React or Next.js** in `src/domain/`.
- Domain types, layout engines, byte budget calculations, and invariant validators can run in any JavaScript/TypeScript runtime (Node.js, Edge Workers, Cloudflare Workers, Web Browsers, Deno).
- Single runtime dependency for validation is `zod@4.6.7`, ensuring robust runtime contract enforcement.

### 3.2 Canonical Invariants Enforced

#### Grid Geometry Invariants
- **Dimensions:** Exactly **40 columns × 25 rows** (`TELETEXT_COLS = 40`, `TELETEXT_ROWS = 25`).
- **Row Allocations:**
  - **Row 1 (Index 0):** Header row displaying Page Number (e.g. `P100`), Service Name (`PAGECAST`), Clock / Date, and Edition.
  - **Rows 2–24 (Indices 1–23):** 23 usable content rows generated by the word-wrapping engine.
  - **Row 25 (Index 24):** Navigation / Fastext shortcut row (Red, Green, Yellow, Cyan color-coded destinations).
- **Cell Structure:** Every row evaluates to exactly 40 logical cells. Span segments are padded or truncated so that `sum(span.length) === 40`.

#### Payload Budget Invariants
- **Ceiling:** Strictly **10 KiB = 10,240 UTF-8 bytes** (`PAGECAST_MAX_PACK_BYTES = 10240`).
- **Measurement:** Deterministically measured using `new TextEncoder().encode(canonicalJson).byteLength`.
- **Benchmark:** The standard 2-page seed pack (`P100` + `P101`) measures **5,836 bytes** (57.0% of the maximum budget), leaving ample room for rich multi-page bulletins.

#### Unicode & Devanagari Hindi Correctness
- Conventional `.length` or regex-based character splitting breaks multi-byte characters and Devanagari conjuncts (e.g. `पेजकास्ट` has `.length === 8`, but visually occupies only 5 grapheme clusters; `नमस्ते` has `.length === 6`, but visually occupies 4 grapheme clusters).
- The `splitGraphemes()` engine uses `new Intl.Segmenter(locale, { granularity: 'grapheme' })`.
- Combining vowel signs (matras), viramas, and conjunct consonants are preserved as cohesive, non-corrupted clusters in every Teletext row.

#### Accessibility (WCAG 2.1 AA)
- Teletext grids rendered visually in green phosphors or multi-color spans can be difficult for screen readers to parse if rendered as individual cell elements.
- The `AccessibleAlternative` component renders a dedicated, structured, semantic `<div className="sr-only" aria-live="polite">` with an accessible page transcript and structured link list, allowing assistive technologies to read bulletins seamlessly.
